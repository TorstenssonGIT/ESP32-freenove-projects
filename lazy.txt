# About Lazy.txt 
Commit it with your changes whenever you update it, like any other file.
Keep it in the repo, but have Git ignore your local edits: run git update-index --skip-worktree lazy.txt. The M disappears and your edits never get committed. To undo, run git update-index --no-skip-worktree lazy.txt.
